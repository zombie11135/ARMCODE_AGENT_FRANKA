部署改动：
  宿主机 hardware/gsnet_ranked.py：复用静止拍摄记录，GPU 推理候选池，
    坐标转换，调用机器人筛选，最终对外保存一个抓取和对应的关节目标。
  宿主机 hardware/gsnet_worker.py：可保留经 NMS 的内部候选池。
  ROS 工作区 scripts/singularity.py / fast_ik.py：按实际 URDF 计算
    Jacobian 指标并并行求解 IK；工作进程不连接机器人或 ROS。
  ROS 工作区 scripts/grasp_screen.py：按抓取得分优先、关节距离其次
    筛选；通过 FK、终点裕量及碰撞后调用已有 MoveIt OMPL RRTConnect。
  ROS 工作区 config/singularity.json：12 个 CPU 进程，每姿态 32 个种子，
    最多 32 个抓取候选、5 次路径规划。MoveIt 规划请求按序执行，
    并非同时调用同一个规划器。实际轨迹末点也重新检查终点门限。
  执行入口固定已选关节目标，从当前状态重新规划；完成后再次检查实际
    末端位姿、静止状态和终点奇异裕量。失败不自动恢复或重试。
