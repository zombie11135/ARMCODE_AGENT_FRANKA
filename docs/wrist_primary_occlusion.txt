腕部主、固定辅助的真机遮挡实验

2026-10-22 新增在线 Agent 接入：见 docs/agent_occlusion_loop.txt。
本文件的 primary-aux 命令仍是只读实验；Agent 在线任务通过
run_fr3_agent.sh --enable_geometry_occlusion 启用带 epoch 失效检查的技能闭环。

当前采用两个独立视角的结果汇总，不依赖固定相机外参。
腕部输出主关系图；固定相机输出独立实例与本视角潜在关系，供人工辅助检查。
不进行跨相机身份合并、三维投影、点云融合或跨视角遮挡确认。
固定相机画面可用于人工发现腕部遗漏候选，程序暂不认定其是新物体或同一物体。
“固定辅助”是逻辑角色，不代表代码已把斜视相机变成俯瞰。实际调整相机朝向后，
未来启用几何融合前须重新标定；本模式仍使用每台相机自己的内参与对齐深度。

保持机械臂和桌面物体静止，运行：

  bash run_occlusion_camera_test.sh primary-aux

仅打开两台 RGB-D 相机；不创建机械臂/夹爪对象，不查询 ROS/FK，不发送运动。
不永久改变 config/hardware/fr3.yaml 的 cameras.mode。
默认最大主机接收时差 100 ms，实测时差写入包内，不声称曝光同步。
相机关闭后再载入 SAM3，先分析腕部，再分析固定视角。每次生成新观测组。
如只需腕部、不希望打开固定相机：

  bash run_occlusion_camera_test.sh primary-aux --wrist-only

复用同一份采集数据，重新运行分割：

  bash run_occlusion_camera_test.sh primary-aux --capture-dir runs/occlusion_real/某次采集

复用已有 SAM3 输出，只重做掩码筛选与单视角关系分析：

  bash run_occlusion_camera_test.sh primary-aux \
    --capture-dir runs/occlusion_real/某次采集 \
    --analysis-dir runs/occlusion_real/某次采集/analysis \
    --output-dir runs/occlusion_real/某次采集/primary_aux_review

输出目录必须尚不存在；已有图片、深度与分析不会被覆盖。
复用前校验观测组、相机序列号、时间、内参、RGB/深度摘要及推理数组原始深度。

算法流程：
1. 每台相机独立采集对齐 RGB-D；无需公共坐标系。
2. SAM3 通用形状提示+重叠裁剪提取可见掩码；不使用药盒文字或目标身份。
3. 对高交叠可见掩码选一个当前解释，保留其余冲突备选。默认交集/较小掩码面积
   达到 0.8 时优先保留模型分数较高的预测；不修改深度，不并集掩码，不提高分数。
   这是分割假设选择，不能证明两个预测属于同一实物；可能误抑制真实物体，需评估。
4. 邻接轮廓取局部深度，区分局部在前与潜在遮挡；不以整物体平均深度排序。
5. 对盒状可见平面拟合，在其可见支持的凸包内作延伸，检查其他实例是否处在
   假设平面之前。仅输出 possible_occludes，不当作隐藏表面实测。
   多个平面对同一有向物体对提供的证据放在一起，不重复计数或当作独立投票。
6. 腕部图作为主结果；固定视角图独立保留，不改变腕部的边或身份。
   边缘截断、缺深度、掩码重叠和相反方向假设分别记录，供复核。

主要输出（采集目录下）：
  camera_preview.png：原始两视角 RGB-D。
  primary_aux_analysis/：原始分割与各视角分析。
  primary_aux/overview.png：腕部在上、固定在下的分割与潜在关系。
  primary_aux/report.json：结构化主辅角色、逐边证据、质量与限制。
  primary_aux/review.txt：便于阅读的当前结果。
  primary_aux/wrist/evidence.png：主视角；N 编号仅对这一画面有效。
  primary_aux/global/evidence.png：辅助视角；N 编号不与腕部对应。
  primary_aux/<相机>/raw_proposal_masks.npz：筛选前的候选掩码，保留备选。
  primary_aux/agent_observation.json：agent 审阅输入草案；execution_enabled=false，
    agent_runtime_connected=false，尚未接入自动清障调度。

图中的橙色箭头是潜在遮挡方向，不代表确认的支撑、碰撞或抓取阻挡。
零边不代表无遮挡；两侧都完全不可见的物体不会被凭空检测到。
实例数是候选数，不是准确的实物数。分数是模型/启发式值，不是成功概率。
每次抓取、清障、放置、人工改动桌面或相机移动后应新建观测组；导出 epoch
只是观测身份标识，本实验入口尚未实现 agent 的自动缓存失效或跨时刻跟踪。

实验评估：
首轮静止采集用于检查覆盖、候选与关系方向；无人工真值时不报告准确率。
随后由操作者布置无遮挡、部分遮挡、完全遮挡、并排相邻、深度缺失等场景。
人工记录真实物体与按视角的遮挡关系，用移开遮挡后的揭示图辅助核对，
但揭示图不得输入当前帧的推理。按实际物体对统计精确率、召回率与漏检，
不能把同一物体的多个分割或多个平面当成多次成功。
本轮用于选择规则的画面是开发样本，后续应固定参数并用新场景独立验证。
