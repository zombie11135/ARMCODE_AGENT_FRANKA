InstaOrder 预训练遮挡关系实验（2026-11-05）

目的与实现
直接使用官方 InstaOrderNet_o 权重，不训练，不重新分割，不合并掩膜。
保留 SAM3 的可见实例及节点编号，模型接收 RGB 和两张可见掩膜，判断两个方向的遮挡。
先沿用现有 boundary/relations.json 的边界邻接、第三物体阻隔和 5% 掩膜冲突规则筛选物体对。
预测阈值使用官方 0.5；分数是未经本场景校准的模型输出，不等于正确率。
保留原有几何候选，补充模型候选；与已确定局部深度顺序或原有边方向冲突时记录冲突。
模型同时给出双向遮挡时保留原始分数待复核，不强行选择单向。
所有输出都是当前视角下 possible_occludes，不能当作物理支撑关系或搬运许可。

代码
occlusion_reasoning/pretrained_order.py：官方模型加载、原始裁剪/归一化、双向平均、几何约束补边。
occlusion_reasoning/replay_pretrained_order.py：读取历史视图、批量推理、全量审计模式、保存图和报告。
tests/test_pretrained_order.py：方向映射、掩膜不变、深度冲突、远邻、第三物体阻隔等反例测试。
没有修改在线 agent 默认配置；本轮完成的是离线可复用后端与实验，不包含实时服务接线。

全量模型最初在腕部给出 16 条有向候选，约束筛选后为 8 条：
排除 5 条无邻接证据、2 条被第三实例隔开的关系、1 条掩膜冲突关系。
默认快速模式在推理前筛选，只推理 8 对；全量审计推理 91 对后筛选，两者最终图一致。
七个视图的快速模式与全量审计图全部一致。
两个分散摆放旧帧均无新增边，但它们缺少紧密接触而不遮挡的困难负例，不能据此声称复杂场景无误报。

耗时与验证
最新腕部候选裁剪+模型推理约 0.050 秒，8 对，RTX 4090 D，cuda:0；模型已加载并预热。
这个计时不含磁盘读取、SAM3、原有几何提取、可视化，也不是整个 agent 的延迟。
此轮模型构建/权重读取约 0.412 秒，首次预热约 0.198 秒；不含 Python 导入和依赖启动。
官方源函数逐项对照 8 个有效物体对、16 次有序输入，输入张量最大误差 0，遮挡方向全部一致。
39 项相关测试通过：tests/test_pretrained_order.py tests/test_occlusion_relations.py tests/test_occlusion_primary_aux.py。
本轮只读取保存数据，没有访问相机、机械臂或夹爪。
