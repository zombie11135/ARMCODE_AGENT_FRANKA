腕部相机图片录入工具

启动
  cd "/home/seur/data/wpy/armcode-agent (1)/armcode-agent"
  bash register_object_photos.sh

  使用 env_armcode_agent 中现有的 Tk / Pillow / pyrealsense2，无需另装 GUI 框架。
  启动时只打开窗口；点击“连接相机”才开启配置中的腕部 D435i 彩色流。
  当前序列号 349622072103，640 × 480，6 fps，来自 config/hardware/fr3.yaml。
  运行本工具前先退出占用相机的 Agent/相机程序。录完后关闭工具，再启动 Agent。
  工具只读取彩色相机，不连接机器人、夹爪或 ROS，不读取机械臂位姿、不启动运动。
  只录入参考照片，不加载 SAM3、AnyGrasp、GroundingDINO 或 MobileCLIP 模型。

操作
  1. 从物品名称下拉框选择已有物品；名称资料、类别和提示词自动带入。
     新物品点击“新物品”，填写标准名称。其他名称用分号分隔，可留空。
     品牌可以共享，但别名代表一个确定的物品；不同产品/规格使用不同名称。
     药盒默认类别 medicine_box，英文检测提示词 medicine package。
     方块可填 cube / block，瓶子可填 bottle / bottle；已登记物品沿用其原类别/提示词。
  2. 点击“连接相机”，查看腕部实时彩色画面；不显示或占用俯瞰相机。
  3. 选择照片视角：正面、侧面、背面、顶面、底面、斜视、未区分。
     标签是人工选择，不自动判别。左右侧面目前统一记为“侧面”。
  4. 点击“拍摄 / 冻结”（F8）。冻结的是当前显示的那一帧，不是之后的新帧。
  5. 在冻结画面上拖动鼠标框住目标物品，右侧显示实际入库裁图。
     可重新拖框；只有整张图片都是该物品时才用“整张图片作为物品”。
  6. 核对名称、视角和裁图，点击“保存并追加”（Ctrl+S），自动恢复预览。
     同一物品继续使用相同名称，换一个朝向或距离重复拍摄即可。
     Esc 取消当前未保存的照片并恢复预览，不删除已经保存的图片。
     表单显示已有图片总数和各视角数量，底部列出本次保存记录。

录入结果
  默认图库 data/object_gallery，与 Agent 当前使用的参考图库完全相同。
  gallery.json：继续使用 schema 2；每个 reference 可新增 viewpoint、capture 元数据。
  images/<hash>.png：实际入库的目标裁图，与已有图库的格式一致。
  captures/<capture_id>/color.png：拍摄的完整彩色原图。
  captures/<capture_id>/capture.json：相机序列号、帧号、时间、原图路径、选框、视角等。
  图库中的 capture 同时记录对应原图路径与选框，便于之后追溯。
  裁图内容完全相同会去重，保留第一次登记的视角和来源，不重复占用完整原图空间。
  正面/侧面是照片标签，不拆成不同身份，不改变现有匹配阈值或候选筛选逻辑。
  历史照片无视角标签的，在界面计为“未区分”。
  下一次 Agent 识别会检测图片变化并重建特征缓存；保存本身不进行推理。
  如果想提前生成磁盘特征缓存，可在录完后手动运行：
    /home/seur/data/wpy/conda_envs/env_armcode_agent/bin/python -m hardware.reference_cli warmup
  warmup 退出后不保留显卡上的模型，Agent 进程仍需首次加载编码器。

其他用法
  界面“打开本地图片”支持已有照片；打开后直接框选并保存，不必重新拍摄。
  完全离线试用界面，建议指定独立图库，防止试用照片进入正式库：
    bash register_object_photos.sh --image /实际图片路径/照片.png \
      --gallery-dir /home/seur/data/wpy/tmp/reference_gallery_demo
  --image 模式不会启动或枚举任何相机。正常相机模式无需此参数。
  --config 指定 references.yaml，--hardware-config 指定相机配置文件。
  原命令行批量导入仍可用，新增可选 --viewpoint：
    /home/seur/data/wpy/conda_envs/env_armcode_agent/bin/python -m hardware.reference_cli \
      register '物品名称' --category medicine_box --prompt 'medicine package' \
      --images /实际图片路径/正面裁图.png --viewpoint front
  可选值：front, side, back, top, bottom, oblique, unspecified。

录入建议
  先为每种物品录入 5–10 张清晰裁图，覆盖当前腕部视角常见的顶部/斜视/侧面。
  不要求每种视角一样多；避免大量几乎完全相同的照片。
  物体完整、目标框少带背景，图片匹配才主要依据物体本身。
  后续准确率测试另拍新图片，不把登记图重复用作独立测试集。
