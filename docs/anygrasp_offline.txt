推理方式
  输入全场景 SDK 点云和 RGB，保留桌面及周边点用于 SDK 内部碰撞检查。
  SDK apply_object_mask=True / collision_detection=True / dense_grasp=False。
  max_gripper_width=0.085 m，gripper_height=0.03 m，top_down_grasp=False。
  SDK 返回后按同一目标框、保存的 SAM 掩码、基座高度过滤；不做 NMS 或 top-K 截断。
  复用保存的 rx/ry 选择参数和 FR3 坐标变换、工具桌面间隙检查。
  未调用 MoveIt、IK、路径规划，未连接硬件。
  两种后端内部碰撞/物体过滤方法不同，候选数和分数不能直接代表抓取成功率。
