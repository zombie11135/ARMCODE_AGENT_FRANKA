FR3 + Robotiq 2F-85 一次抓取流程
2026-10-13

入口：run_gsnet_pick.sh；实现：hardware/gsnet_pick.py。
宿主机 env_armcode_agent 负责相机、GSNet、手眼变换和 USB 夹爪；
机械臂继续调用已有 Docker real 服务中的 ROS 2 + MoveIt 2。
入口不会启动/重启 Docker，也不会切换 Desk 模式。

运行前：保持已有 real 栈运行、FCI 激活，机械臂处在静止、能看清盒子的
观察位置；关闭占用腕部相机或夹爪串口的旧程序/控制台。
相机使用已标定的腕部 D435i（349622072103），不使用另一台相机。

完整执行（由操作者运行）：

  cd "/home/seur/data/wpy/armcode-agent (1)/armcode-agent"
  bash run_gsnet_pick.sh --execute

不用先 conda activate；脚本固定使用
  /home/seur/data/wpy/conda_envs/env_armcode_agent/bin/python
也可以直接用上述 Python 运行 -m hardware.gsnet_pick --execute。

实际顺序：
  1. 建立夹爪只读通信会话，持续后台轮询（不在这一步激活/开合）。
  2. 读取拍摄前法兰位姿、拍摄新 RGB-D/完整点云、读取拍摄后法兰位姿。
     验证相机身份、彩色光学坐标系和拍摄期间静止状态。
  3. GSNet 推理；按原有分数/开口/桌面高度/点云近似碰撞过滤，只输出
     最高分的一条。不翻转 180°，失败不自动更换第二条抓取。
  4. 使用拍摄时法兰位姿和已配置手眼、18 cm TCP 变换目标。
  5. 先规划预抓取目标；检查不通过时不激活/开合夹爪。
  6. 如夹爪未激活则执行激活自标定，随后完全张开；不自动清除故障。
  7. 移动到沿抓取接近方向后退 8 cm 的预抓取位姿。
  8. 移动到同一抓取的最终法兰位姿；确认执行成功及到位后闭合夹爪。
  9. 只有夹爪报告闭合接触（gOBJ=2）时才抬升。默认从闭合后的实际
     法兰位姿出发，将目标基座 Z 增加 0.05 m，目标姿态保持不变。
 10. 保持夹爪通信，等待操作者查看或手动释放；不自动返回/放下。

各段使用现有 MoveIt PTP 重规划和执行，允许绕行，不保证接近/抬升严格
沿笛卡尔直线。本轮不做轨迹最短化或奇异回避优化。
此次新入口在每个请求中指定 singularity_screening=advisory：只记录
奇异指标，不强制应用上一轮奇异性/额外关节裕量门限，也不强制换到
上一轮筛选的远距离关节构型。IK 候选优先选择靠近当前关节状态的解。
现有 ranked 入口与全局配置保持其原有终点筛选模式。
机械臂自身错误、控制器执行结果、位姿误差、碰撞、真实关节限位和
速度/加速度/加加速度检查仍有效，不会忽略执行故障。

参数：

  bash run_gsnet_pick.sh
    仅拍摄、推理、导出目标和从当前状态规划预抓取；不连接夹爪串口，
    不激活运动控制器。它不是完整三段轨迹的串联仿真。

  bash run_gsnet_pick.sh --execute --lift 0
    闭合后停在抓取位置，不抬升。

  bash run_gsnet_pick.sh --execute --roi X0 Y0 X1 Y1
    只允许图像矩形内的抓取参考点。默认整幅 640x480 图像，未沿用
    旧拍摄的盒子像素范围。ROI 外点云仍保留用于近似指爪碰撞检查。

  --config PATH / --gsnet-root PATH / --output-dir PATH
    指定硬件配置、模型工程、新的输出目录。已有运行目录不会被覆盖。

  --no-hold
    流程结束后退出并关闭夹爪通信；不自动释放。通常保留默认会话，
    避免停止轮询后再次出现曾见过的通信 0x09。此参数用于需要自行
    管理通信生命周期的调用方。

结束时的 pick> 控制台：
  status  读取夹爪状态
  open    张开并释放（执行你输入的命令）
  stop    停止夹爪运动
  quit    退出，不自动张开；停止后台通信
Ctrl+C 在动作期间会中断该次操作并执行现有清理；随后若夹爪会话已经
建立，则保留通信控制台。再次 Ctrl+C 或 quit 退出。
机器人运动期间检查夹爪会话；抬升期间另检查夹持接触。故障会请求取消
本脚本拥有的机械臂工作进程，并等待其停止控制；不恢复、不重抓。

输出目录：runs/gsnet_pick/时间戳/
  run.json                  各步结果、最终状态、错误与机器人日志路径
  events.jsonl              按时间追加的阶段和手动夹爪命令记录
  observation/capture/     本次 RGB-D、点云、相机信息
  observation/capture_pose.json  拍摄前后实际法兰位姿与标定快照
  observation/gsnet/       最高分抓取、图像叠加、三维预览、推理统计
  observation/targets.json 预抓取/抓取坐标、手眼和工具配置
具体机械臂轨迹及执行日志仍在 ROS 工作区 logs/agent/。

gOBJ=2 表示检测到闭合接触，不能单独证明盒子稳定夹持。run.json 的
grasp_success_visually_verified 保持 false，由操作者观察验证。
MoveIt 目前建模机器人、桌面和整套工具包络；盒子点云用于 GSNet
指爪筛选，未加入沿途机器人碰撞模型，也未作为抬升后的附着物建模。

验证：新增流程用模拟设备检查顺序及失败分支；关联 ROS/FR3/GSNet/
Robotiq 离线测试共 133 项通过。助手没有运行实机抓取/激活/开合。

Open3D 对比视图（新增）

  bash run_gsnet_pick.sh --o3d
    拍摄、推理并打开点云/目标视图；关闭后仅继续预抓取规划，不运动。

  bash run_gsnet_pick.sh --execute --o3d
    拍摄推理后先显示目标；关闭窗口后继续已启用的真机抓取流程。
    抓取/抬升成功后再打开结果视图，叠加实际末端到达位置；关闭后
    返回夹爪通信控制台。窗口标题也标明关闭后将发生的动作。

可视化在独立进程运行，主进程继续维持夹爪后台只读轮询。
前置可视化失败则不继续动作；执行完成后的可视化失败单独记录，
不会自动重做已经完成的抓取。仍保留不带 --o3d 的原有入口。

随时重新查看某次保存的结果，不拍摄、不推理、不连接任何硬件：

  bash view_gsnet_o3d.sh runs/gsnet_pick/你的时间戳目录

也支持之前的 gsnet_single 和 gsnet_ranked 目录。例如用历史执行日志
对比同一个抓取的计划目标和实际到达值：

  bash view_gsnet_o3d.sh runs/gsnet_single/20261013-193640 \
    --robot-log /home/seur/data/wpy/armcode_agent/logs/agent/b86ce1c97ef04111a22f8f8f31eeccd6.jsonl

历史查看使用当时保存的相机位姿和标定快照，不套用当前位姿/新标定。
若手动提供的执行日志目标与抓取目标不同，拒绝混在一起对比。

图例：
  绿色：GSNet 原始抓取，使用 GraspNet API 通用平行夹爪示意。
  橙色：目标法兰处的完整工具包络（含 padding），不是夹爪实体 CAD。
  蓝色：预抓取 TCP 标记及其与抓取 TCP 的连接线。
  紫色：有执行记录时，实际抓取工具包络及各阶段实际 TCP 位置。
  RGB 坐标轴分别表示 X/Y/Z。初始显示法兰和 TCP；A 切换 GSNet 轴，
    再按 A 隐藏坐标轴，再按 A 返回法兰/TCP，避免两套轴重合混淆。
  所有几何统一在基座 fr3_link0 中，单位 m。

G/E/P/O/T 分别开关抓取、工具包络、预抓取、实际到达、桌面网格。
C 回到拍摄方向，B 切换基座斜视角；鼠标旋转/缩放；S 保存截图。
Q/Esc/窗口关闭按钮结束本次查看，不是机械臂停止命令。
点云是拍摄时的静态场景；紫色数据来自机器人模型 FK 反馈，不是
动作后的新点云。蓝色连接线是目标关系示意，不是 MoveIt 规划轨迹。

截图和 view.json 视角文件保存在 RUN_DIR/o3d/；scene.json 保存视图
使用的变换矩阵与实际反馈。--check-only 可只构建几何而不打开窗口；
--screenshot FILE.png 可在图形桌面中用不可见窗口生成一张截图并退出。

点云和旧执行日志在本机 Open3D 0.19.0 中生成对比截图。没有发送新动作。
